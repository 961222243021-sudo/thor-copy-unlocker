# Privacy Policy

**Thor – Copy & Paste Unlocker**

_Last updated: October 23, 2026_

## Summary

Thor is designed to run in the user's browser. Its extension code stores the list of sites where the feature has been disabled using browser local storage. The current source code is not designed to send this settings data to a remote server.

## Information and permissions

- **Browser local storage:** Used to save the user's per-site enable/disable settings.
- **Webpage access (`<all_urls>`):** Used so the content scripts can operate on webpages where the extension is permitted to run.
- **Screen recording:** Recording is started by the user from the extension interface. The browser's own sharing picker asks the user to choose the screen, window, or tab and grant access. The user can stop recording and download the resulting file.

## Data sharing

The current project source does not intentionally transmit extension settings or recorded media to a developer-operated server. Users should review the source code of the exact version they install, especially if the project changes in future releases.

## User control

Users can disable Thor for a website through the popup, stop a recording, remove the extension, or clear the browser's extension data through browser settings.

## Children's privacy

Thor is a general-purpose browser utility and is not specifically directed at children.

## Changes

This policy should be updated if future versions add analytics, remote services, data transmission, or other data processing.

## Contact

For privacy questions, open an issue in this repository. Do not post private or sensitive information in public issues.
