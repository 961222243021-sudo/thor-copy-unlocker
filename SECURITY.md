# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security issues or sensitive details in a public issue.

For now, report suspected vulnerabilities through a private contact method listed on the repository owner's GitHub profile. If no private contact method is available, open a minimal issue asking for a secure reporting channel without including exploit details.

## Supported versions

Security fixes are considered for the latest version maintained in this repository.

## Scope

Please report issues involving unintended data exposure, unsafe handling of page content, unexpected recording behavior, or permissions beyond what the extension needs.
