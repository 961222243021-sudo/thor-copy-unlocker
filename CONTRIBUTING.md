# Contributing to Thor

Thanks for your interest in improving Thor – Copy & Paste Unlocker.

## Before you start

- Search existing issues to avoid duplicates.
- For major changes, open an issue first to discuss the proposal.
- Keep changes focused and explain why they are needed.
- Never include credentials, private data, or personal recordings in a pull request.

## Development workflow

1. Fork the repository.
2. Create a branch for your change.
3. Make the change and test it in the target browser.
4. Review the browser console and extension errors.
5. Update documentation if behavior, permissions, or setup instructions change.
6. Submit a pull request describing the change and the tests performed.

## Code and privacy expectations

- Keep processing local where practical.
- Do not add analytics, telemetry, or remote data transmission without clearly documenting it and updating the privacy policy and store disclosures.
- Request only permissions that are necessary.
- Do not weaken browser security or misrepresent the extension's capabilities.
- Respect copyright, privacy, and website terms.

## Bug reports

Include the browser and version, operating system, steps to reproduce, expected behavior, actual behavior, and relevant console errors. Remove personal or confidential information before sharing logs.

## Pull requests

Please include a clear summary, test steps, screenshots when useful, and any documentation changes.
